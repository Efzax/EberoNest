# v1.0.0 — Initial Release

EberoNest automatically sorts new Downloads by configurable category and file extension. Manage rules in the dark EberoNest interface, keep the organizer in the Windows system tray, and optionally start it when you sign in.

- Per-user Windows installer
- Local rules and file organization
- No telemetry; files and rules are not sent to the Internet
- Downloaded files are not executed
- Unsigned installer; Windows SmartScreen may display an unknown publisher warning
