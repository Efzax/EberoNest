# v1.0.1 — Update Notifications

EberoNest can now check the official GitHub Releases for new stable versions, making it easier to know when an update is available while keeping the update process fully under your control.

### What's new

- Automatic update check when EberoNest starts, at most once per day
- Manual **Check for updates** option in About
- Discreet notification when a newer stable version is available
- Direct link to the corresponding official EberoNest GitHub Release
- Improved About/footer layout integration

### Privacy & security

- Update checks connect only to the official `Efzax/EberoNest` GitHub repository
- No telemetry or analytics
- Files, rules and Downloads contents are never sent
- No automatic downloads
- No automatic installation or execution of updates
- Network failures do not affect file organization

Updates remain entirely optional: EberoNest only notifies you when a newer version is available.

### Installation

Download **`EberoNest-Setup_v1.0.1.exe`** below and run it.

If EberoNest is already installed, the installer can update the existing installation while preserving your rules.

> **Note:** EberoNest is currently unsigned. Windows SmartScreen may display an unknown publisher warning.
