# EberoNest v1.0.2 — Localization & Windows Integration

EberoNest v1.0.2 brings Spanish and English support and a more complete integration with Windows, while keeping file organization and update decisions under your control.

### What's new

- Use EberoNest in **Español** or **English**.
- Change the language immediately from About; your choice is saved for future sessions.
- A dark title bar integrates with the EberoNest interface while keeping the native Windows title bar, window controls, and Snap Layouts.
- About has been updated with the current product information and language selector.
- A new official EberoNest icon family is used according to the surface: the app icon for the main application identity, a compact icon in window title bars, and distinct normal and organizing states in the system tray.
- Improved Start Menu and Windows Search integration, including a shortcut name correction so Windows presents the app as **EberoNest** rather than **EberoNest.lnk**.
- Safely recognized legacy and duplicate-extension shortcuts are cleaned up during installation.
- The optional Update Checker introduced in v1.0.1 remains integrated.

### Privacy & security

- No telemetry or analytics.
- Rules, language preference, and files remain on your computer; EberoNest does not send them to the Internet.
- The Update Checker connects only to the official `Efzax/EberoNest` GitHub repository to check for stable releases.
- EberoNest does not download, install, or run updates automatically. Updates remain optional.
- The installer is not digitally signed, so Windows SmartScreen may display an unknown publisher warning.

### Installation

Download **`EberoNest-Setup.exe`** from the v1.0.2 GitHub Release and run it. Setup installs EberoNest for the current Windows user. If you are upgrading, your existing rules are preserved.
